# Support

## Bug reports and questions

Use [GitHub Issues](https://github.com/montasim/BugReceipt/issues) for non-sensitive bugs, installation problems, and usage questions. A useful report includes:

- the BugReceipt version and Chrome version;
- the page type or a safe public reproduction URL;
- the expected and actual behavior;
- exact steps to reproduce;
- whether screen, console, network, export, or email delivery failed.

Do not attach captures, recordings, screenshots, credentials, personal information, or production request bodies until you have reviewed and removed sensitive content.

## Security issues

Use the private process in [SECURITY.md](SECURITY.md). Do not report suspected vulnerabilities in a public issue.

## Project boundaries

BugReceipt is a pre-release Chrome extension distributed as an unpacked ZIP. Chrome Web Store installation, Firefox and Safari support, authenticated GitHub or Linear issue creation, and automatic interaction-step generation are not currently supported.
